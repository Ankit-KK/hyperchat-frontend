# Homepage Creator’s Toolkit refinement

Home opts into CreatorFeatures' `depth` variant. The dedicated Features page
keeps its current presentation. Inset charcoal navigation, an ivory selected tab,
a raised preview frame, and a distinct description surface extend the hero's
material hierarchy. Copper marks selection; muted olive accents the frame and
category label. The preview counter is decorative and does not duplicate the
accessible tab announcement.

All seven demos and keyboard tab controls are preserved. On phones the tabs
form a two-column grid above the preview, with smaller static shadows. No new
animation, dependency, backend behavior, or continuous rendering work is added.

Validation: production build; seven existing mobile interaction tests passed.
Desktop, tablet and phone screenshots checked. All seven tabs were visited at
each size with no horizontal overflow. Automated accessibility checks on the
initial toolkit view reported no violations at each size.
